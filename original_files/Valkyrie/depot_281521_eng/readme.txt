1. SYSTEM REQUIREMENTS
======================

Windows XP SP2; Pentium 4 2.4 MHz or higher; GeForce 6600 with 128 Mb RAM or higher; 512 Mb system RAM; DirectX compatible sound card; 4x DVD-ROM; 2,4 Gb freespace on HDD, keyboard, mouse.

2. GAME INSTALLATION
==========================
Put "Ascension to the Throne. Valkyrie" DVD into DVD-ROM. Autorun screen will appear. Click "Install" and follow instructions.

NB: If "Auto Insert Notification" function is disabled on your system, Autorun screen will not appear. In this case, you should run Setup.exe from your DVD-ROM manually.

When the installation process is complete, you may launch the game either from "Start" menu or from game folder by running ATThrone.exe.

4. Known Issues
===============
Game may become unstable or may not start on AGP videocards with onboard RAM 128 Mb or lower. 
In order to fix it, try the following:

1. In the "Options" menu, set "Textures" to "Low",
2. In the BIOS, set AGP Apperture Size to maximum value (Advanced->Chipset->AGP Apperture Size 
(Graphic Apperture Size)

Game may not start if you set unsupported monitor resolutoin in the video settings. In this case delete file "graphic.cfg" in the game folder.
